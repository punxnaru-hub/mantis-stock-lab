# MANTIS Stock Lab — Android + 웹 대시보드

이 패키지는 MANTIS v1 연구용 백테스트를 버튼 중심의 웹 화면으로 실행하도록 구성했습니다. 화면은 모바일 브라우저에도 맞춰집니다. 별도 Android APK는 아니며, Chrome에서 열어 홈 화면에 추가해 앱처럼 사용할 수 있습니다.

## 가장 쉬운 사용: Streamlit Community Cloud (스마트폰/PC 공용)

### 준비물
- Google 계정
- GitHub 계정
- 이 폴더의 파일 전체

### 배포 순서
1. https://github.com 에 로그인하고 새 저장소(repository)를 만듭니다. 예: `mantis-stock-lab`
2. 이 폴더 안의 파일 4개(`app.py`, `mantis_backtest.py`, `requirements.txt`, `README_KR.md`)를 저장소 루트에 업로드합니다.
3. https://share.streamlit.io 에서 GitHub 계정으로 로그인합니다.
4. **Create app**을 누르고 저장소, 브랜치(`main`), 메인 파일(`app.py`)을 선택한 뒤 Deploy 합니다.
5. 배포가 끝나면 발급된 `https://....streamlit.app` 주소를 Android Chrome과 PC에서 모두 엽니다.
6. Android Chrome 메뉴(⋮) → **홈 화면에 추가**를 누르면 아이콘으로 바로 접속할 수 있습니다.

배포 과정은 최초 한 번만 하면 됩니다. 이후에는 같은 주소로 접속합니다. 데이터 제공처 정책이나 서버 리소스에 따라 다운로드가 지연되거나 제한될 수 있습니다.

## PC에서 직접 실행
Python 3.10 이상을 설치한 뒤 이 폴더에서 터미널을 열고 실행:

```bash
pip install -r requirements.txt
streamlit run app.py
```

브라우저에서 `http://localhost:8501`을 엽니다.

## 한국/미국 종목 입력 예시
- 미국: `NVDA,MSFT,AMZN`, 벤치마크 `SPY`
- 한국: `005930,000660,035420`, 벤치마크 `1001` (코스피) 또는 `2001` (코스닥)

## 계산과 해석 주의
- 신호는 일봉 종가로 계산하고 다음 거래일 시가에 진입하는 가정입니다.
- 수수료와 슬리피지를 반영합니다. 실제 증권사 비용·세금·체결 차이와 다를 수 있습니다.
- 미국 시장의 외국인/기관 신원별 수급은 무료 일봉 데이터에서 신뢰성 있게 제공되지 않으므로 임의로 만들어 넣지 않습니다.
- 한국 수급 데이터는 pykrx가 반환하는 투자자별 순매수 거래대금 컬럼을 사용합니다. 데이터 공급처/API 변경으로 수급이 비어 있을 수 있습니다.
- 종목별 거래를 각각 복리 계산한 연구 결과이며, 여러 종목을 동시에 보유하는 포트폴리오의 자금 제약·비중·현금 관리는 아직 구현하지 않았습니다.
- 상장폐지 종목 누락 등 생존편향, 거래정지, 상하한가, 배당·분할, 유동성, 시장국면 문제를 완전히 처리하지 않았습니다.
- 실제 시장 데이터에 대한 백테스트 결과는 사용자가 실행한 뒤에만 생성됩니다. 이 패키지 자체는 수익률 우위를 입증하지 않습니다.

## 문제 해결
- `No module named ...`: 배포 플랫폼의 앱 로그에서 의존성 설치 오류를 확인하고 재배포합니다.
- `No data`: 종목 코드, 기간, 데이터 공급처 응답을 확인합니다.
- 한국 종목에서 수급 컬럼이 비어 있으면 가격·거래량 분석은 가능할 수 있지만 수급 가중치가 결측일 수 있습니다. 수급 결측을 매수 우위로 해석하지 마세요.
